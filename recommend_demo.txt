 全文总结
================================================================================

 两个程序对比着看，你会发现"变的只有三样东西"：

                     第 1 个程序                第 2 个程序
  ----------------------------------------------------------------
  任务               分类（10 选 1）            回归（猜 1 个数）
  输入               784 个像素                 用户 id + 电影 id
  输出的形状         (N, 10)                    (N, 1) -> (N,)
  损失函数           CrossEntropyLoss           MSELoss
  最后一步           不接激活（自带 softmax）   接 sigmoid 压到 0~1
  评价指标           准确率                     RMSE
  看数据的方式       自己解析二进制文件         按行读文本文件
  ----------------------------------------------------------------
  相同的部分         nn.Module、nn.Linear、ReLU、DataLoader、
                     Adam、以及那四行训练循环

 这几处相同的地方，才是你要真正记住的东西。以后不管换什么任务——
 图像、文本、推荐、时序——这四行永远是这个顺序：

     optimizer.zero_grad()
     loss.backward()
     optimizer.step()

 而"数据 -> 模型 -> 损失 -> 优化器 -> 循环 -> 评估"这个流程，
 你可以直接套到导师给你的下一个任务上。
