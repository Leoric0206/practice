================================================================================
 第一部分：读代码之前，先花三分钟认识 Python 的基本写法
================================================================================

 1. 缩进就是"代码块"。
    C 语言用 { } 把几条语句括起来，Python 用"缩进 4 个空格"。
    同一缩进的一批行属于同一块。缩进错了程序直接报错（IndentationError）。
    这是所有新手遇到的第一个坑。

 2. 很多行以冒号 : 结尾。
    冒号的意思是"下面缩进的那一块归我管"。
    if、for、def、class、with、try 这些行后面都要有冒号。

 3. 不写分号，不声明类型。
    C 要写  int a = 10;   Python 直接写  a = 10 。
    变量只是一个名字，贴到 10 这个数上。名字可以随时改贴到别的东西上。

 4. # 开头的是注释。
    从 # 到这一行结尾，解释器当它不存在。给人看的。

 5. 三引号 """...""" 是一段字符串。
    写在文件最上面、或者函数第一行的三引号字符串，习惯用来写大段说明（叫 docstring）。
    程序运行时它什么都不干，只是被 Python 存进 __doc__ 里备查。

 6. 函数这样写：
        def 名字(参数1, 参数2):
            函数体（缩进）
            return 结果
    Python 的函数可以一次返回好几个值：return a, b，
    接收的时候写  x, y = f()  就行了。

 7. 列表和字典：
        [1, 2, 3]                叫列表，相当于 C 的数组，但能装不同类型的东西。
        {"a": 1, "b": 2}         叫字典，是"键 -> 值"的查表，相当于哈希表。

 8. for 循环是"遍历"：
        for x in 列表:            依次把列表里每个元素取出来叫 x。
        for i in range(5):        i 依次是 0,1,2,3,4（从 0 开始，不含 5）。

 9. None 相当于 C 的 NULL（空指针）。True 和 False 首字母必须大写。

10. 点号 . 表示"里面的"：
        model.parameters()       调用 model 里面的函数 parameters
        torch.cuda               取 torch 里面的 cuda 这个东西

11. f"..." 叫 f-string：字符串前面加个 f，里面 { } 的内容会被替换成实际的值。
        f"准确率 {acc:.2%}"      把 acc 按百分比显示、保留两位小数，塞进这句话里。

12. 括号没配对完时可以直接换行。
    一行写不下，只要 ( [ { 还没闭合，回车换行接着写完全没问题。

    打开这个 .gz 压缩文件，并且把打开的文件对象起名叫 f。

      "rb"        读二进制模式（read binary）。不能用 "r"，因为里面是压缩过的字节；

第 88 行 |         # frombuffer 要求缓冲区可写，所以这里用 bytearray 转一下

第 89 行 |         raw = bytearray(f.read())
    f.read() 一次性把解压后的所有字节读出来（训练集图片约 4700 万字节）。
    bytearray(...) 把这些字节装进一个"可修改的字节数组"里。
    为什么要转？因为下一行用的 torch.frombuffer 要求这块内存是可写的，
    而 f.read() 直接给的是只读的 bytes。

第 90 行 |     # 文件头 16 字节是说明信息（魔数、图片数、行数、列数），从第 16 字节才是像素
    注释：解释 MNIST 的文件格式。
    这个文件开头 16 个字节不是图片，是四段说明（文件类型标记、图片总数、行数、列数），
    真正的像素数据从第 16 个字节开始。

第 91 行 |     pixels = torch.frombuffer(raw, dtype=torch.uint8, offset=16)
    把这段内存"直接当成数字数组来看"：
      raw                刚才拿到的字节数组；
      dtype=torch.uint8  每个字节解释成 0~255 的无符号整数；
